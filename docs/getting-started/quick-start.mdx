# Quick Start

This Quick Start guide shows how to run your first Bacalhau job with minimal setup. Bacalhau's design as a single self-contained binary makes it incredibly easy to set up your own distributed compute network in minutes.

By the end of this guide, you'll have:
- ✅ Installed Bacalhau locally
- ✅ Started your own compute network
- ✅ Submitted and run a data processing job
- ✅ Retrieved and viewed the results

## Prerequisites

- **Docker** installed on any machine that runs a compute node
- **Bacalhau CLI** installed (see below)
- **Basic terminal knowledge** for running commands

## 1. Installation

1. Install Bacalhau using the one-liner below (Linux/macOS) or see the [installation guide](./installation.mdx) for Windows and Docker options.

```bash
curl -sL https://get.bacalhau.org/install.sh | bash
```

2. Once installed, verify with:

```bash
bacalhau version
```

You should see output showing the Bacalhau version and build information.

## 2. Start a Hybrid Node

Open a terminal and run:

```bash
bacalhau serve --orchestrator --compute
```

**What this does:**
- Launches both an orchestrator and a compute node in one process
- Creates a complete Bacalhau network on your local machine
- Starts listening for jobs to process

Keep this terminal open and running. You'll see logs indicating the node is ready to accept jobs.

## 3. Submit a Data Analysis Job

Bacalhau supports two primary methods of job submission: **Imperative (CLI)** and **Declarative (YAML)**. We'll demonstrate a word count analysis job on the classic novel Moby Dick.

<Tabs groupId="job-submission">
<TabItem value="Imperative (CLI)" label="Imperative (CLI)">

Run this single command to submit your job:

```bash
bacalhau docker run \
  --input https://www.gutenberg.org/files/2701/2701-0.txt:/data/moby-dick.txt \
  --output outputs:/outputs \
  --publisher local \
  ghcr.io/bacalhau-project/word-count:latest -- --output-file /outputs/moby-dick-counts.txt /data/moby-dick.txt
```

**What this does:**
- Downloads Moby Dick text from Project Gutenberg
- Runs a word count analysis using a containerized tool
- Saves results to a local directory

</TabItem>

<TabItem value="Declarative (YAML)" label="Declarative (YAML)">

Create a `word-count.yaml` file:

```yaml
Type: batch
Count: 1
Tasks:
  - Name: main
    Engine:
      Type: docker
      Params:
        Image: ghcr.io/bacalhau-project/word-count:latest
        Parameters:
          - --output-file
          - /outputs/moby-dick-counts.txt
          - /data/moby-dick.txt
    Publisher:
      Type: local
    InputSources:
      - Alias: input_custom
        Target: /data/moby-dick.txt
        Source:
          Type: urlDownload
          Params:
            URL: https://www.gutenberg.org/files/2701/2701-0.txt
    ResultPaths:
      - Name: outputs
        Path: /outputs
```

Then run the job using:

```bash
bacalhau job run word-count.yaml
```

**Benefits of YAML approach:**
- Version controllable job definitions
- Easier to share and reproduce
- Better for complex job configurations

</TabItem>
</Tabs>

After submission, Bacalhau will:
1. Display job progress as it processes
2. Print a **Job ID** (save this for the next steps)
3. Show completion status

## 4. Monitor the Job

Check your job's status and details:

```bash
# Get detailed job information
bacalhau job describe <jobID>

# View execution logs
bacalhau job logs <jobID>

# List all your jobs
bacalhau job list
```

Replace `<jobID>` with the actual ID printed in step 3.

## 5. Retrieve Results

Download and examine your job results:

```bash
# Download the results to your local machine
bacalhau job get <jobID>

# View the word frequency analysis
head job-*/outputs/moby-dick-counts.txt
```

:::success Congratulations! 
You should see a word frequency analysis showing the most common words from Moby Dick, like:

```
the: 14620
of: 6732
and: 6502
a: 4799
to: 4707
```
:::

## What Just Happened?

You've successfully:

1. ✅ **Started a local Bacalhau network** - Your machine became both an orchestrator and compute node
2. ✅ **Submitted a distributed job** - The word count analysis ran in an isolated Docker container
3. ✅ **Processed remote data** - Bacalhau downloaded and processed the text file automatically
4. ✅ **Retrieved structured results** - The output was saved and made available for download
