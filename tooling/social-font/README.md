Bundled Nunito Sans font from Google Fonts, used by the existing site design.

Source: https://github.com/google/fonts/tree/main/ofl/nunitosans

The supplied variable font was pinned to weight 700 with FontTools using a static instance and unchanged font timestamps. The Open Font License is included in OFL.txt. Builds use only the bundled font and do not access the network or system fonts.
