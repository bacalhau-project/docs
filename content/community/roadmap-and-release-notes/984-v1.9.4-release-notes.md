# Bacalhau v1.9.4 Release Notes

Bacalhau v1.9.4 was released on September 5, 2026. This maintenance release has no configuration, CLI, or API changes.

## Security build

Bacalhau binaries are now built with Go 1.26.6, which picks up the security fixes in that Go release.

## Dependency maintenance

The release also updates Go dependencies (including gRPC and protobuf), Web UI dependencies, and the Python SDK, Python client, and operations tooling dependencies.
