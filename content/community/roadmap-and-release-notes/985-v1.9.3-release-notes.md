# Bacalhau v1.9.3 Release Notes

Bacalhau v1.9.3 was released on August 9, 2026. This maintenance release has no configuration, CLI, or API changes.

## Dependency maintenance

The release:

- updates Go dependencies, including gRPC;
- updates Web UI dependencies and keeps the Web UI on compatible upgrades;
- updates the Python SDK, Python client, and operations tooling dependencies, including `cryptography` 50; and
- clarifies the open-source project identity in the repository.
