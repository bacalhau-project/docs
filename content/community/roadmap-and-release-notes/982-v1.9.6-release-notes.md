# Bacalhau v1.9.6 Release Notes

Bacalhau v1.9.6 was released on November 25, 2026. This maintenance release has no configuration, CLI, or API changes.

## Dependency maintenance

The release:

- updates Go dependencies across the core module and integration tests;
- updates Web UI dependencies, including Next.js 16.4.6; and
- updates Python SDK, Python API client (raising the `urllib3` floor to 2.8.0), and operations tooling dependencies.
