# Bacalhau v1.9.5 Release Notes

Bacalhau v1.9.5 was released on October 12, 2026. This maintenance release has no configuration, CLI, or API changes.

## Toolchain and runtime dependencies

- Bacalhau binaries are now built with Go 1.26.9.
- containerd is updated to 2.2.8.

## Dependency and CI maintenance

The release also:

- updates Go, Web UI, and Python dependencies; and
- replaces withdrawn MinIO and unreachable IPFS downloads in the project's test jobs.
